# Runbook: regenerate the Excel formula cache

## When to run this

* You generated a workbook with `build_*_excel_workbook.py` and a parity test
  is reading wrong values from `data_only=True`.
* `ModelCheck` cells show `None` or `0` even though formulas are present.
* Diff between two consecutive runs shows changes only in cached values, not
  formulas.

## Why this happens

`openpyxl` writes the formulas you set, but every cell that holds a formula
*also* has a separate cached `value` slot. When openpyxl loads with
`data_only=True`, it returns the **cached** value, not the formula result.
A workbook that was just generated by openpyxl has *no* cache for its
formulas; only Excel (or `xlcalculator`/`pycel`) computes and writes them.

This means: any Python code that reads `wb["Sheet"]["B5"].value` from a
freshly-built workbook with `data_only=True` gets `None` or stale data.

## Procedure

1. **Confirm the workbook has formulas** (not values):
   ```bash
   python - <<'PY'
   from openpyxl import load_workbook
   wb = load_workbook("SPIA.xlsx", data_only=False)
   ws = wb["ModelCheck"]
   for row in ws.iter_rows(min_row=5, max_row=12, max_col=2):
       for cell in row:
           print(cell.coordinate, repr(cell.value))
   PY
   ```
   Expect strings starting with `=` for the B column. If you see numbers, the
   workbook was never formula-built; this runbook does not apply.

2. **Recompute via Excel / LibreOffice** -- needed for human inspection:
   * macOS: `open -a "Microsoft Excel" SPIA.xlsx`, then `Cmd+S` to persist
     the cache.
   * Headless: `libreoffice --headless --calc --convert-to xlsx SPIA.xlsx`.
     LibreOffice recomputes all formulas and writes the cache before saving.

3. **Recompute via Python (preferred for tests)** -- use the helper in
   `recalc_excel_shared.py`:
   ```python
   from recalc_excel_shared import recalculate_workbook
   recalculate_workbook("SPIA.xlsx")
   ```
   The helper invokes `xlcalculator` (or LibreOffice as a fallback) and
   writes the cache.

4. **Validate after recalc** -- always:
   ```python
   from openpyxl import load_workbook
   from excel_workbook_validator import validate_workbook_or_raise
   wb = load_workbook("SPIA.xlsx")
   validate_workbook_or_raise(wb)
   ```

## Pitfalls

* **Never** read with `data_only=True` from a workbook that was not
  recalculated. The values are not what the formulas would produce; they are
  whatever was cached at last save.
* **Excel for Mac** sometimes silently uses the system locale for decimal
  separators -- if you see `1,234.56` formulas where you expected
  `1234.56`, force the workbook through `libreoffice --convert-to xlsx`.
* **The Streamlit UI's "Run pricing" button** uses `data_only=False` plus
  Python recompute, so it is unaffected. Only the headless CSV /
  parity-test path needs explicit recalc.
